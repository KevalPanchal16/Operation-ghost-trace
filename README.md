# Operation: Ghost Trace

### GDGoC NFSU Gandhinagar — Cybersecurity Lead Challenge

A two-challenge, offline digital forensics and network forensics mini-CTF.

## Challenges

**01 — The Paper Trail**
- Category: Digital Forensics / Log Analysis
- Difficulty: Beginner
- Skills: Log correlation, evidence reconstruction and Base64 decoding.

**02 — DNS After Dark**
- Category: Network Forensics / DNS Analysis
- Difficulty: Experienced
- Skills: PCAP analysis, DNS investigation, Base32 decoding and XOR decryption.

## Project Contents

All project files are available in the `GDGoC_Ghost_Trace/` directory.

- Challenge player evidence
- Organizer challenge cards and walkthroughs
- CTFd hosting guide
- Artifact validation script
- SHA-256 integrity checks
- Submission documentation

## Validation

Run the validator from inside the project directory:

```bash
python tools/validate_artifacts.py
```

## Safety

Both challenges use synthetic evidence and are designed for offline investigation. No real targets or credentials are involved.
